# CSV to Snowflake Uploader

This project provides a Python script to read a cleaned CSV file and upload its data into a Snowflake database table.

## Features

- Reads data from a CSV file using `pandas`
- Cleans and formats the data (if needed)
- Connects to Snowflake securely using environment variables
- Uploads data to a specified Snowflake table using `write_pandas`
- Logs connection and data transfer status
